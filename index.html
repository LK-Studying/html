Thẻ Code là gì, dùng để làm gì?

  • 1.Sử dụng khi có 1 đoạn code =>trình duyệt sẽ hiểu đây là 1 đoạn code
  • 2.Thể hiện đây là 1 khối code độc lập => không bị thụt lề vào trong
  • 3.Thường dùng kèm thẻ pre để giữ định dạng code

demo bằng cách sử dụng hết thẻ head nhưng không dùng kèm thẻ pre

<head> <meta charset="UTF-8" /> <meta name="viewport" content="width=device-width, initial-scale=1.0" /> <title>Tag code</title> </head>

demo bằng cách sử dụng hết thẻ head nhưng dùng kèm thẻ pre

<head> 
    <meta charset="UTF-8" /> <meta
    name="viewport" content="width=device-width,
    initial-scale=1.0" /> <title>Tag code</title>
